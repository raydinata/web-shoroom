# GARASI RAY - Showroom Motor Semarang

GARASI RAY adalah website showroom motor yang menampilkan katalog unit Honda dan Yamaha di Semarang. Website ini dirancang dengan desain modern, responsif, dan interaktif.

## Fitur Utama

- **Katalog Motor Interaktif**: Pencarian, filter berdasarkan merek/tipe, dan sorting harga/nama.
- **Simulasi Kredit**: Perhitungan angsuran otomatis dengan opsi salin ringkasan.
- **Booking Online**: Booking service dan cek sparepart langsung via WhatsApp.
- **Perbandingan Motor**: Fitur untuk membandingkan spesifikasi dua motor.
- **Desain Modern**: Fully responsive dengan animasi *scroll reveal* dan interaksi pengguna yang halus.

## Struktur Proyek

- `index.html`: Struktur utama website.
- `style.css`: Desain, layout, dan animasi.
- `script.js`: Logika interaksi, filter, sorting, dan animasi.
- `Data.js`: Data produk, promo, dan konfigurasi showroom (Edit file ini untuk update data).

## Panduan Edit Data

Buka `Data.js` untuk:
- Mengubah informasi showroom (Nama, WA, Alamat, Jam, Sosial Media).
- Menambah/mengubah daftar produk (Honda/Yamaha).
- Menambah promo atau testimoni pelanggan.
